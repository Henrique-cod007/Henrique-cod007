## Projetos

- **(Fingrow: aplicativo de educação financeira)** — *(Estou desenvolvendo do zero um aplicativo voltado a educação
- O aplicativo FinGrow tem como objetivo fornecer uma plataforma de aprendizado voltada para educação financeira, pensado para um público-alvo de jovens no ensino médio e fundamental.
Nossa abordagem será focada em estruturar as lições com base no nível de complexidade dos conteúdos, criando trilhas de aprendizado interativas sobre um tema específico. Os módulos representam uma unidade  da trilha de aprendizado, encapsulando uma lição, podendo ser explicada por meio de textos, vídeos e atividades interativas. Para finalizar uma trilha, o usuário responderá a um questionário para demonstrar o seu domínio sobre o assunto. Como forma de adicionar uma camada de realidade e interatividade, o aplicativo contará com uma área de investimentos simulada. O intuito dessa área é proporcionar um ambiente para o usuário aplicar os conhecimentos adquiridos em um simulador de investimento. Para isso, o usuário utilizará créditos que podem ser obtidos com a finalização das trilhas.
Para incentivar o hábito de investir e engajar o usuário, as trilhas mais avançadas precisam ser desbloqueadas com o uso dos créditos.
